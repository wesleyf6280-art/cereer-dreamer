# Problemas relatados pelo cliente

## #01 — O botão “Descobrir minha carreira” não faz nada
**Prioridade:** alta · **Dificuldade:** fácil

O formulário deve validar os dados e enviar uma requisição POST para `CONFIG.API_URL`. Se a API não estiver configurada, deve abrir o modal “Tente mais tarde”. Erros HTTP ou de rede devem ser informados ao usuário.

## #02 — O campo Nome não aceita texto corretamente
**Prioridade:** alta · **Dificuldade:** fácil

O campo deve aceitar nomes com letras, espaços, apóstrofos, hífens e pontos; exigir de 2 a 60 caracteres; e não aceitar vazio ou nome de um único caractere.

## #03 — Os campos do formulário ficam apertados
**Prioridade:** média · **Dificuldade:** fácil

Os campos devem ser apresentados verticalmente, com espaçamento e boa adaptação a telas pequenas.
